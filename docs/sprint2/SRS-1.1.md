## 1. Вступ

### 1.1 Призначення
Документ визначає вимоги до вебзастосунку «ФінКит» — кабінету онлайн-банкінгу для фізичних осіб компанії «ФінКит Банк» — та до модуля бізнес-логіки нової функції «Кредитний калькулятор і заявка онлайн». Призначений для відділу забезпечення якості, розробників модуля та замовника як підстава приймання.

### 1.2 Обсяг
До обсягу входять функції кабінету клієнта від реєстрації до виходу та звернення до служби підтримки (розділ 3), вимоги до інтерфейсу користувача (розділ 4), а також правила модуля бізнес-логіки: кредитний калькулятор, валідатор переказів, книга обліку рахунку (розділ 5) і нефункціональні вимоги (розділ 6). Поза обсягом: мобільний застосунок, робочі місця операціоніста та ризик-менеджера, карткові продукти, сповіщення e-mail/SMS.

### 1.3 Терміни і скорочення

| Термін | Визначення |
| :--- | :--- |
| **Клієнт** | Фізична особа з обліковим записом у «ФінКит» і щонайменше одним рахунком. |
| **Кабінет клієнта** | Сторінки, доступні після входу: рахунки, операції, налаштування. |
| **Рахунок** | Поточний (`checking`) або ощадний (`savings`) рахунок клієнта з балансом у гривнях. |
| **IBAN** | Міжнародний номер банківського рахунку (International Bank Account Number); для України — префікс `UA` і 27 цифр (регулярний вираз `^UA\d{27}$`). |
| **Ануїтетний платіж** | Рівний щомісячний платіж за кредитом (частина основної суми плюс відсотки). |
| **Денний ліміт** | Найбільша сумарна сума переказів клієнта за календарну добу (50 000,00 грн). |
| **Овердрафт** | Списання, після якого баланс рахунку став би від'ємним (у системі «ФінКит» заборонено). |
| **РНОКПП** | Реєстраційний номер облікової картки платника податків (у поточній версії demo — поле `SSN`). |

### 1.4 Посилання
* Каталог продуктів — картка продукту П2 «ФінКит».
* Модуль бізнес-логіки «ФінКит» версії 1.0.0 — `README.md` у `code/modules/finkit/v1/`.
* Поточна версія продукту (demo): [parabank.parasoft.com](https://www.google.com/search?q=https%3A%2F%2Fparabank.parasoft.com%2Fparabank%2Findex.htm); резерв — [GlobalSQA Banking Project](https://www.google.com/search?q=https%3A%2F%2Fwww.globalsqa.com%2FangularJs-protractor%2FBankingProject%2F).

## 2. Загальний опис

### 2.1 Користувачі та ролі

| Роль | Що робить у системі |
| :--- | :--- |
| **Клієнт** | Реєструється, входить і виконує всі операції кабінету за розділом 3. |
| **Операціоніст** | Обслуговує клієнтів у відділенні; у поточній версії окремого робочого місця не має. |
| **Ризик-менеджер** | Визначає параметри автоматичного кредитного рішення (мінімальний баланс, спосіб оцінювання, поріг). |
| **Адміністратор** | Сторінка адміністрування: ініціалізація та очищення даних (`Initialize` / `Clean`), режим доступу до даних, параметри застосунку. |

### 2.2 Середовище
Вебзастосунок для браузерів Chrome або Firefox актуальних версій; поточна версія розгорнута за адресою з розділу 1.4. Модуль бізнес-логіки — бібліотека Java 17 (Maven 3.9, без зовнішніх залежностей у робочому коді; тести — JUnit 5).

### 2.3 Обмеження і припущення
1. Усі суми — у гривнях з точністю до копійки; символ «$» у поточній версії читати як «грн» 1:1.
2. Дані поточної версії періодично скидаються: створені під час тестування облікові записи і рахунки можуть зникнути.
3. Мова інтерфейсу поточної версії — англійська; підписи і повідомлення в документі — їх українські еквіваленти.
4. Поле «РНОКПП» відповідає полю `SSN`, «Область» — `State`, «Поштовий індекс» — `Zip Code`.
5. Параметри кредитного рішення (спосіб опрацювання заявки — за доступними коштами `Available Funds`, за першим внеском `Down Payment` або комбінований `Combined` — та поріг у відсотках, за замовчуванням у demo 20 %) задає адміністратор на сторінці адміністрування (`/admin.htm`).
6. Сповіщення e-mail та SMS не надсилаються; підтвердження показуються на сторінці.

## 5. Вимоги до бізнес-логіки модуля

Модуль — окремий Maven-проєкт (пакет `ua.kpi.tzyapz.finkit`, класи `LoanCalculator`, `TransferValidator`, `AccountLedger`). Усі грошові величини — тип `java.math.BigDecimal`; результати округлюються до двох знаків після коми (копійок) за правилом `HALF_UP`; проміжні обчислення не округлюються. Позначення: `P` — сума кредиту (грн), `r` — річна ставка (%), `n` — строк (місяців), `i` — місячна ставка у частках, `A` — щомісячний платіж (грн).

| ID | Формулювання | Пріоритет |
| :--- | :--- | :--- |
| **BL-10** | `LoanCalculator.monthlyPayment(principal, annualRatePercent, months)` обчислює щомісячний ануїтетний платіж за формулою `A = P · i / (1 − (1 + i)^−n)`, де `i = r / 12 / 100`. Результат — `BigDecimal` із двома знаками після коми, округлення `HALF_UP`. | High |
