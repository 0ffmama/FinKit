## 2. Структура артефактів Спринта 2 у папці `docs/sprint2/`

* [requirements-defects.md](https://www.google.com/search?q=.%2Frequirements-defects.md) — Реєстр дефектів вимог специфікації `SRS_02_ФінКит` (версія 1.0): містить матрицю розподілу розділів, зведену статистику, повний Реєстр на 24 підтверджені дефекти (по 4 на кожний із 6 критеріїв якості вимог) + 2 відхилені записи та протокол обговорення спірних питань.
* [SRS-1.1.md](https://www.google.com/search?q=.%2FSRS-1.1.md) — Виправлена специфікація вимог до програмного продукту «ФінКит» (версія 1.1 після аудиту) з повним **Журналом змін** на початку (без перенумерації наявних ідентифікаторів вимог).
* [test-plan.md](https://www.google.com/search?q=.%2Ftest-plan.md) — План тестування продукту «ФінКит» (межі тестування, усі 7 обов'язкових рівнів тестування, 16 застосовних типів із пріоритетами та 8 незастосовних типів із обґрунтуванням природою продукту, тестові дані з префіксом `GD-`, аналіз ризиків).
* [tasks.md](https://www.google.com/search?q=.%2Ftasks.md) — Таблиця розподілу задач Спринта 2 (Шаблон 2), матриця подвійного незалежного аудиту розділів `SRS 1.0` та покроковий план роботи команди.
* [retro-sprint2.md](https://www.google.com/search?q=.%2Fretro-sprint2.md) — Протокол ретроспективи Спринта 2 за схемою `Start / Stop / Continue` та рішеннями на Спринт 3.
