## 1. Продукт і межі тестування

**1.1 Що тестуємо:** Вебзастосунок онлайн-банкінгу для фізичних осіб (реєстрація, перегляди рахунків, перекази), а також нову функцію «Кредитний калькулятор і заявка онлайн» разом із її модулем бізнес-логіки.

**1.2 У межах тестування:** Функції кабінету клієнта за специфікацією SRS 1.1 (розділ 3: реєстрація, авторизація, огляд рахунків, відкриття рахунків, перекази, кредитний калькулятор). Модуль бізнес-логіки `ua.kpi.tzyapz.finkit` (розділ 5). Вимоги до GUI та нефункціональні вимоги продуктивності (P-10, P-20).

**1.3 Поза межами тестування:** Мобільний застосунок, робочі місця операціоніста та ризик-менеджера, карткові продукти, сповіщення e-mail/SMS (згідно з SRS 1.2). Будь-які функції ParaBank, не описані у специфікації «ФінКит».

**1.4 Ролі користувачів у тестуванні:** Основна роль для виконання на demo — Клієнт. Внутрішні ролі (Ризик-менеджер, Операціоніст, Адміністратор) використовуються виключно на рівні бізнес-логіки та сценаріїв перевірки налаштувань лімітів.

## 5. Інструменти, середовище, тестові дані

**5.1 Інструменти:** JDK 17, Maven 3.9, JUnit 5 для модульного тестування; Selenium WebDriver для UI-автотестів; Postman для перевірки API; браузери Chrome та Firefox актуальних версій; JMeter для тестування продуктивності.

**5.2 Середовище:** Основне середовище — ParaBank (`parabank.parasoft.com`). Резервне середовище — GlobalSQA Banking Project. Для заборонених на публічному demo тестів (навантажувальне, безпекове) розгортається ізольований локальний резерв у Docker. Увага: дані періодично скидаються, що вимагає ініціалізації.

**5.3 Тестові дані:** 
Усі записи іменуються з префіксом `GD-` (Група D). Дані є вигаданими, без використання реальних персональних інформацій.
- **Облікові записи:** `GD-Client1`, `GD-Client2`.
- **Суми переказів:** На межах (0 грн, -100 грн, рівно сума балансу, 50 000 грн для денного ліміту).
- **Параметри кредиту:** Межа суми (999 грн, 1000 грн, 1 000 000 грн), ставка (5%, 40%).
- **Рахунки:** Валідні та невалідні формати українського IBAN (`UA` + 27 цифр).
